# Visual Continuity

## Assign references deliberately

Give each `Image N`, `Video N`, or `Audio N` one primary responsibility. Separate identity, wardrobe, location, prop design, motion, camera rhythm, dialogue, and ambience across references instead of asking every asset to control everything. When two references appear to conflict, preserve the responsibility explicitly assigned by the current request and ask for clarification if the priority is not recoverable.

## Stable traits and scene-state deltas

Maintain two lists while drafting:

- Stable traits: identity, facial structure, body proportions, wardrobe design, prop design, location layout, and recurring visual style.
- Scene-state deltas: pose, expression, gaze, wetness, dirt, damage, prop position, weather intensity, time-of-day shift, and lighting change.

Carry stable traits across shots. Update a scene-state delta only after a described cause or requested transition, then preserve the new state until another visible change occurs.

## I2V discipline

Treat the source image as the existing first-frame evidence. Describe motion, reaction, camera behavior, and requested transformation after that frame. Avoid re-specifying visible anatomy, wardrobe, framing, colors, or light in ways that fight the source. Preserve the source composition, colors, and lighting unless the request calls for a deliberate transition, and then describe the cause and progression of that transition.

For first-and-last-frame work, name the two image responsibilities and connect them with a plausible visual path. Preserve screen direction, identity, prop ownership, and accumulated state through the transition.

## Recurring continuity

Track the same character name and reference responsibility in every shot. Preserve wardrobe layers, accessories, held objects, prop ownership, damage, stains, wetness, weather direction, shadow direction, practical light sources, and time-of-day logic. When a state changes, show the event that changes it or state the requested transition clearly.

Use precise preservation language without unsupported guarantees. Ask to maintain recognizable identity, defining traits, wardrobe, or layout; do not claim `100% match`, `pixel-perfect`, exact reproduction, or guaranteed consistency.

## Audio references

Use an audio reference only for separable exact dialogue or non-musical ambience such as room tone, wind, rain, traffic, machinery, footsteps, or impacts. Do not inherit music, melody, singing, rhythm tracks, beat synchronization, or a musical timing structure from audio. If the useful dialogue or ambience cannot be separated from music, ask for a clean source or a text description of the intended non-musical element.
